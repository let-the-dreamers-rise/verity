Every day each host gets prompts carrying one-time bait: a private document link and a fake API key that exist nowhere else. If anything ever opens that link or tries that key, the prompt left the host's serving path. The bait's hashes are made public before a single prompt is sent, so a hit cannot be invented after the fact.

Method

How a result is made

Nothing here relies on trusting Verity. The requests are open, and every response is published.

Same requests, every host

One fixed set of requests goes to each host of a model at temperature 0, in shuffled order, with no announcement.

Hosts are compared with each other

Identical output must cost identical tokens. A tool call must fit its schema. Answers must finish. Peers set the baseline, not us.

Evidence is public and hashed

Every response is committed to the repository with a SHA-256, so any score can be recomputed and none can be quietly edited.
