The host that bills you also reads the meter.

Verity sends the same unannounced requests to every host of the same open model, then compares what came back and what was billed. Every number links to raw evidence anyone can re-check.

    What gets measured

    Token ratio

    Hosts are asked to repeat a fixed text. Identical output must cost the same tokens, so each host's billed count is divided by the median across hosts. Above 1.15 is flagged.

    Tool calls

    Share of function-calling requests that return the right tool with arguments that pass the schema. Below 90% is flagged.

    Cut-offs

    Share of long answers that came back empty or stopped before the requested end marker. Above 5% is flagged.

    Agreement

    How closely a host's answers at temperature 0 match the closest half of its peers. Low agreement can mean a different or squeezed model. Below 0.60 is flagged.

    A flag is a measurement that crossed a provisional threshold, not an accusation. Small samples and honest configuration differences can all cause one. Hosts can reply or dispute a result by opening an issue.
